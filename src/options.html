PR Tab Groups settings

Azure DevOps

Enter the organization name or its dev.azure.com URL.

Use Code (Read). Project and Team (Read) is also needed when scanning the whole organization. Create an Azure DevOps PAT.

Enter one repository per line as Project/Repository or an Azure DevOps repository URL. When empty, every accessible repository is scanned.

⚠️ Full organization scan enabled. Every accessible repository is queried on each sync; use a repository list or a 15-minute-or-longer interval to reduce Azure DevOps API traffic.

GitHub

Use a fine-grained token with Pull requests (Read) and Contents (Read) for the selected repositories. Create a GitHub token.

Enter one repository per line as owner/repository or a GitHub repository URL.

Shared behavior

Active PRs created by these identities stay in My open PRs when a commit author or Co-authored-by trailer matches your provider identity.

Only tabs tracked by a previous successful sync are affected. Unrelated tabs are never closed or moved.
